# Prototipos

Cada subcarpeta es un mini-proyecto Godot independiente y descartable, pensado
para probar una sola mecánica antes de invertir en el juego principal
(`../games/justiciero/`).

Convención por prototipo:
- `project.godot` propio (no comparte proyecto con Justiciero).
- `README.md` corto: qué mecánica prueba y qué se aprendió.

Todavía no hay prototipos creados.
